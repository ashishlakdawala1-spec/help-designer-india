# HELP Designer India — Website

Static marketing site for **HelpDesignerIndia**, a fashion consultancy and end-to-end sourcing/manufacturing service (Founder: Sheetall Modi, Surat, India).

Single-page responsive site with four sections: **Home → About → Services → Book a Consultancy Call**.

## Tech
Plain HTML, CSS, and a little JavaScript — no build step. Hosted on GitHub Pages.

- `index.html` — page markup
- `styles.css` — styling
- `script.js` — mobile menu + scroll animations
- `assets/` — images

## Local preview
```bash
python -m http.server 5500
```
Then open http://localhost:5500
